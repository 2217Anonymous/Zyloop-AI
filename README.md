# Architect Studio (React + Tailwind)

Same-UI conversion of the MegaOne Architect Studio HTML theme.

## Run

```bash
cd react-app
npm install
npm run dev
```

Open http://localhost:5173/

- `/` — Home (one-page)
- `/blog` — Blog list
- `/blog/:slug` — Blog detail

The original HTML in the parent folder is kept as the visual reference. Contact form validates on the client only (no PHP mailer in this copy).
